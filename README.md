# Overview
**SeqForge** is a modular, bash-based bioinformatics pipeline designed for the complete processing of **paired-end (PE) sequencing data** from Illumina technologies, culminating in highly filtered genetic variant calls. It is structured into two sequential modules, _**genopipe**_ and _**vcfpipe**_, providing a robust and traceable workflow from raw reads to refined variants.

## Core Function and Structure
The pipeline is engineered to handle **raw (demultiplexed) paired-end read files** that utilize CASAVA 1.8+ FASTQ headers. Its primary function is to transform this raw data into a **high-quality VCF (Variant Call Format) file** ready for downstream genetic analysis.

## Module Breakdown
1. _**genopipe**_ (Paired-end Reads Processing Pipeline): This module handles all aspects of raw read preparation and alignment. It ensures data quality by sorting, synchronizing, and filtering raw reads. It then maps these clean reads to a user-provided reference genome, removes PCR artifacts (duplicates), and performs the initial call of genetic variants (SNPs and Indels), preparing the necessary files for the next stage.

2. _**vcfpipe**_ (VCF Processing Pipeline): This module specializes in refining the variant calls. Its purpose is to take the VCF file generated by _**genopipe**_ (or other genetic variant callers) and apply rigorous, multi-layered filtering. This includes applying quality thresholds at both the site and genotype levels, and critically, detecting and removing potential paralogous sites to enhance the quality of the final variant set.

In summary, **SeqForge** provides a unified and systematic framework to take raw Illumina data through the essential steps of alignment, quality control, and robust variant filtering, yielding a high-confidence set of SNPs (and Indels).
